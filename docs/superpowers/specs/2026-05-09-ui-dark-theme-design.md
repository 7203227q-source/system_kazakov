## Контекст

Нужна тёмная тема интерфейса для учеников и репетиторов (админу не нужна) и переключатель между тремя режимами:
- Light (классическая белая)
- Dark (серо-синяя)
- Dark Classic (почти чёрная)

Важно: в проекте уже есть `preferred_theme` (classic/dota/cs2/ussr) — это тема задач/сеттинг. UI-тему нельзя смешивать с этим полем.

## Цели

1) Добавить хранение UI-темы в профиле пользователя (в БД), чтобы сохранялось между устройствами.
2) Дать переключатель UI-темы для ролей student и tutor.
3) Применять UI-тему ко всем страницам student_* и tutor_*.
4) Не менять внешний вид админских страниц (admin_dashboard и platform-admin).

## Решение

### A) Модель и миграция

- Добавить в `User` поле `ui_theme`:
  - значения: `light`, `dark`, `dark_classic`
  - default: `light`

### B) Endpoint для переключения

- Добавить view `update_ui_theme_view` (POST):
  - доступ: `request.user.role in ['student','tutor']`
  - валидировать значение (в списке допустимых)
  - сохранить в `request.user.ui_theme`
  - редирект обратно на referer

### C) Применение темы в шаблонах

- Добавить общий include `core/includes/_ui_theme_css.html` с CSS overrides, которые меняют базовые Tailwind-классы (`bg-white`, `bg-gray-50`, `text-gray-*`, `border-gray-*`) при наличии класса на `<body>`:
  - `ui-dark` (серо-синяя палитра)
  - `ui-dark-classic` (почти чёрная палитра)

- В шаблонах student_* и tutor_* добавить:
  - `{% include 'core/includes/_ui_theme_css.html' %}` в `<head>`
  - класс на `<body>`:
    - если `user.ui_theme == 'dark'` → `ui-dark`
    - если `user.ui_theme == 'dark_classic'` → `ui-dark-classic`

### D) Переключатель темы

- В сайдбаре ученика и репетитора добавить select:
  - “Классическая белая”, “Тёмная”, “Классическая чёрная”
  - отправка POST на `update_ui_theme`

## Критерии готовности

- Ученик и репетитор могут переключать UI-тему, выбор сохраняется в БД.
- Все student_* и tutor_* страницы отображаются корректно в dark/dark_classic.
- Админские страницы не получают тёмную тему и не меняются.
