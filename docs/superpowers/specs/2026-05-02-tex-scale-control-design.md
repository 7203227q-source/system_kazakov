## Цель

Добавить вверху страницы «Банк заданий» (tutor_task_bank) временный контрол для подбора масштаба формул, чтобы пользователь мог интерактивно менять размер отображения формул без правок кода и перезагрузки страницы.

## Контекст и проблема

На странице «Банк заданий» формулы отображаются через MathJax (tex-mml-chtml). В некоторых задачах (например, 116125) формулы выглядят заметно меньше основного текста. Требуется оперативный способ подобрать подходящий масштаб.

## UX

- Размещение: над списком карточек задач (после фильтров/поиска, перед выводом задач).
- Контрол: слайдер «Масштаб формул» + текстовое отображение значения в процентах.
- Диапазон: 90–180%.
- Шаг: 5%.
- Значение по умолчанию: 100%.
- Персистентность: значение сохраняется в localStorage и применяется при загрузке страницы.

## Поведение

- При изменении слайдера обновляется CSS-переменная `--tex-scale` на корневом элементе (document.documentElement).
- Масштаб применяется к двум типам формул:
  - MathJax CHTML-рендер: через `mjx-container` (изменение `font-size`).
  - Inline-картинки формул: через `.prose img.tex` (изменение `height`).

## Техническая реализация

### Шаблон

- В `core/templates/core/tutor_task_bank.html` добавить блок управления масштабом (HTML) перед выводом списка задач.
- В блок добавить:
  - `input[type="range"]` с id `tex-scale-range`
  - `span` с id `tex-scale-value`

### CSS

- Установить дефолт `--tex-scale: 1`.
- Применение масштаба:
  - `mjx-container { font-size: calc(var(--tex-scale, 1) * 1em); }`
  - `.prose img.tex { height: calc(var(--tex-scale, 1) * 1.35em); }`

### JS

- На DOMContentLoaded:
  - Прочитать сохранённое значение из localStorage (ключ `texScalePercent`), иначе 100.
  - Выставить значение слайдера и текста.
  - Применить `--tex-scale`.
- На событие `input` слайдера:
  - Обновить текст.
  - Применить `--tex-scale`.
  - Сохранить процент в localStorage.

## Ограничения и риски

- Решение предназначено как «временное» (оперативный тюнинг) и может быть заменено на постоянные настройки масштаба по умолчанию после подбора.
- Изменение `font-size` для `mjx-container` не требует повторного typeset и не должно вызывать мерцание, но влияет на перерасчёт верстки.

## Критерии готовности

- На странице «Банк заданий» появляется слайдер масштаба над списком задач.
- Перетаскивание слайдера сразу меняет размер формул MathJax и inline-картинок `.tex`.
- Значение сохраняется и восстанавливается после перезагрузки страницы.
