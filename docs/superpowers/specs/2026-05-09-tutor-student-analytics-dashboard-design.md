## Контекст

В панели репетитора нужно видеть прогресс выбранного ученика:

- график успеваемости (мастерство) и прогнозного балла;
- возможность смотреть разные масштабы (30 дней / 90 дней / 365 дней с агрегацией по месяцам);
- диаграмму «решаемости по номерам» (1–19) по всем решениям ученика, с градиентной подсветкой от красного (0%) до зелёного (100%).

Источник данных:
- `DailySnapshot` (date, current_mastery, predicted_exam_score) — для графиков.
- `Submission` + `Task.task_type.number` — для решаемости по номерам.

## Цели

1) Добавить в `tutor_dashboard` блок аналитики выбранного ученика с графиками.
2) Добавить в `tutor_dashboard` диаграмму/heatmap по номерам задач (1–19), по всем попыткам (включая тренажёр и варианты).
3) Сохранить простоту: без новых моделей и без внешних сервисов.

## Решение

### 1) График «Мастерство» и «Прогнозный балл»

- UI:
  - выбор предмета (по `StudentSubjectProfile.subject`) — по умолчанию первый профиль ученика;
  - выбор периода: 30 / 90 / 365.
- Backend:
  - достаём `DailySnapshot` ученика по выбранному предмету;
  - если период 30/90 — используем дневные точки;
  - если период 365 — агрегируем по месяцам (среднее `current_mastery` и среднее `predicted_exam_score`).
- Frontend:
  - `Chart.js` line chart с двумя линиями: мастерство (%) и прогноз (/100) на одной оси 0..100.

### 2) Решаемость по номерам (1–19) с градиентом

- Данные:
  - берём все `Submission` выбранного ученика;
  - группируем по `task__task_type__number`;
  - считаем `total` и `correct` (по `is_correct=True`);
  - `rate = correct/total * 100`, если `total=0` → `None`.
- UI:
  - плитки или горизонтальные бары по номерам 1..19;
  - цвет считается на клиенте по `rate` (HSL hue 0..120).
  - для `None` показываем «нет данных» (серый).

### 3) Параметры URL и сохранение контекста

Все переключатели работают через query-string и сохраняют:
- `student_id` (какой ученик выбран),
- `subject_id` (для графиков),
- `range` (30/90/365).

## Критерии готовности

- В `tutor_dashboard` у выбранного ученика виден график с переключением периода.
- В `tutor_dashboard` видна диаграмма решаемости 1–19 с градиентом.
- Загрузка страницы не падает, когда у ученика нет snapshots или нет решений.
