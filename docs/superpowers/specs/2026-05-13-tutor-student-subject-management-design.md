# Управление предметами ученика у репетитора (вариант A)

## Контекст и проблемы
1) Репетитору нужно управлять предметами ученика прямо в `tutor_dashboard`:
   - добавлять новый предмет ученику;
   - выбирать формат экзамена внутри предмета (`StudentSubjectProfile.exam_format`) и дату экзамена.
2) У некоторых учеников у репетитора диаграммы/решаемость по номерам не соответствуют формату экзамена, выбранному учеником (или текущему предмету).
3) Возможен сценарий нескольких репетиторов у одного ученика. На первом этапе принимаем вариант A: любой привязанный репетитор видит/редактирует все предметы ученика (без закрепления предметов за репетиторами).

## Цели (MVP инкремент)
1) Добавить в `tutor_dashboard` возможность **добавить предмет** ученику:
   - создать `StudentSubjectProfile(student, subject)` если его нет;
   - проставить дефолтный `exam_format` для предмета (активный, иначе самый новый).
2) Сделать так, чтобы все расчёты/отображения **решаемости по номерам** у репетитора:
   - строились строго по `StudentSubjectProfile.exam_format` выбранного предмета;
   - использовали набор номеров из `TaskType` этого `exam_format` (а не захардкоженные диапазоны).
3) Упростить диагностику: показывать в UI рядом с решаемостью явный бейдж **«Формат: …»**.

## Не цели (в рамках этого инкремента)
- Фото/проверка ИИ для развернутой части.
- Решаемость по номерам в дашборде ученика.
- Закрепление предметов за репетиторами (вариант B) и разграничение прав.

## Данные и источники истины
**Источник формата для предмета ученика:**
- `StudentSubjectProfile.exam_format` для `(student, subject)` — основной.
- fallback (если `exam_format` пуст): `ExamFormat(subject=subject, is_active=True)` или самый новый по `year`.

**Источник списка номеров:**
- `TaskType.objects.filter(exam_format=profile.exam_format).order_by("number")`.

## UI изменения (tutor_dashboard)

### 1) Добавить предмет ученику
Блок в секции «Экзамен»:
- `select` выбора `Subject` (из всех `Subject`, которых ещё нет у ученика);
- кнопка `Добавить`.

### 2) Отображение решаемости по номерам
Где бы ни отображалась “решаемость по номерам”:
- подписать «Формат: {{ active_profile.exam_format.name }} {{ active_profile.exam_format.year }}»;
- список плиток/точек строить по `TaskType` выбранного `exam_format`.

## Поведение для нескольких репетиторов (вариант A)
- `StudentSubjectProfile` общая сущность ученика.
- Любой репетитор, привязанный к ученику (`student.tutors`), может:
  - добавлять предмет ученику;
  - менять `exam_format` и дату экзамена.
Риски: возможны конфликты настроек между репетиторами; их решаем в следующем инкременте при переходе к варианту B.

## Тестирование
1) Юнит/интеграционный тест: репетитор добавляет предмет через `POST` → создаётся `StudentSubjectProfile` и выставляется `exam_format`.
2) Тест: решаемость/плитки в `tutor_dashboard` строятся по `TaskType` активного `exam_format` (количество плиток соответствует количеству `TaskType`).
