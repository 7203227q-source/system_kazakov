## Контекст

Удалять пользователей через Django admin неудобно. Нужна возможность удаления из кастомной панели администратора (`/platform-admin/`), прямо из таблицы пользователей.

## Цель

- Добавить кнопку удаления пользователя в списке пользователей на админ-дашборде.
- Доступ только для `role=admin`.
- Удаление жёсткое (`User.delete()`), как просит пользователь.

## Ограничения и безопасность

- Минимальная защита — браузерный `confirm()` (как запрошено).
- Запретить удаление пользователей с `role=admin` (чтобы не снести админов случайно).

## Решение

### Backend

- Добавить view `admin_delete_user(request, user_id)`:
  - `@login_required`, `@require_POST`
  - Проверка `request.user.role == 'admin'`
  - Загружаем `User` по `id`, проверяем `user.role != 'admin'`
  - Удаляем пользователя: `user.delete()`
  - `messages.success(...)` и редирект обратно на `admin_dashboard` с сохранением query-string (page/role/q).

- Добавить URL:
  - `path('platform-admin/users/<int:user_id>/delete/', views.admin_delete_user, name='admin_delete_user')`

### Frontend

- В таблице пользователей (`admin_dashboard.html`) добавить кнопку с иконкой корзины в колонку «Действия».
- Кнопка — это `<form method="POST">` с CSRF и `onsubmit="return confirm('...')"` чтобы не делать delete через GET.

## Критерии готовности

- Админ может удалить пользователя прямо из списка пользователей.
- Не-админ получает отказ (403 или редирект на login).
- Попытка удалить `role=admin` блокируется сообщением об ошибке.
