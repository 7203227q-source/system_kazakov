# Technical Design: Task Variants & CSV Import

## 1. Context
The platform needs to support thematic variations of tasks (e.g., Classic, Dota, USSR) while retaining the core mathematical logic and correct answer. We also need a mechanism to mass-import these tasks from a CSV/Excel file (likely generated by an AI like GenSpark) and automatically download remote images to our local server.

## 2. Database Models
Modify `core/models.py`:
- **Task**:
  - Add `subtype_tag` (CharField, null=True, blank=True) for semantic grouping.
  - Remove `content` (will be migrated to `TaskVariant`).
- **TaskVariant** (New Model):
  - `task` (ForeignKey to `Task`, related_name='variants')
  - `theme` (CharField, default='classic')
  - `content` (TextField) - HTML content with image tags.
  - `solution` (TextField, null=True, blank=True) - Step-by-step solution.

*Note on Migration*: We must carefully migrate existing `Task.content` to a new `TaskVariant(theme='classic')` before removing the `content` field from `Task` to avoid data loss.

## 3. CSV Import Logic
Create a new view or admin action to handle CSV uploads.
- **Input**: CSV file with columns `fipi_id`, `type_number`, `subtype_tag`, `difficulty`, `correct_answer`, `theme`, `content`, `solution`.
- **Processing**:
  1. Read CSV rows.
  2. Get or create `Task` by `fipi_id`. Update fields (`type_number` -> `TaskType`, `subtype_tag`, `difficulty`, `correct_answer`).
  3. Parse HTML in `content` and `solution`. Find `<img src="...">`.
  4. Download images using `requests`, save to `media/tasks/`, and replace `src` with the local URL.
  5. Update or create `TaskVariant` for the given `theme`.

## 4. UI Updates
- **Admin/Tutor Dashboard**: Add an "Import Tasks (CSV)" button and a simple file upload form.
- **Student Profile**: Add a dropdown to select the preferred theme (saved in the `User` model as `preferred_theme`).
- **Task Rendering**: Update `student_practice.html`, `tutor_task_bank.html`, etc., to display the `TaskVariant` matching the user's preferred theme (fallback to 'classic').
