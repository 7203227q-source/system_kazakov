# Награды от репетитора (XP) — Design

**Goal:** Добавить возможность репетитору вручную начислять ученику XP по выбранному предмету, с сохранением истории начислений (кто/когда/за что/сколько), и отображением в кабинете репетитора.

---

## Контекст (как сейчас)

- XP ученика хранится в `StudentSubjectProfile.xp` и увеличивается автоматически при решении задач.
- В кабинете репетитора уже есть кнопка “Дать +50 XP” в `tutor_dashboard.html`, но она не связана с бэкендом.
- В системе мультипредметность реализована через `StudentSubjectProfile` (по предметам), поэтому награда должна быть привязана к предмету.

---

## Предложение (реализация)

### 1) Модель данных

Добавить новую таблицу (название: `TutorReward`):
- `tutor` → FK(User)
- `student` → FK(User)
- `subject` → FK(Subject)
- `xp_amount` → PositiveInteger
- `reason` → Text (короткая причина)
- `created_at` → DateTime auto_now_add

### 2) Правила доступа и валидация

- Начислять XP может только пользователь `role='tutor'`.
- Репетитор может начислять XP только ученику, который есть в его списке (`request.user.students` содержит ученика).
- `subject` должен существовать у ученика (есть `StudentSubjectProfile`).
- `xp_amount` ограничить разумным диапазоном (например 1..500).
- `reason` опционально, но если передан — ограничить длину (например до 300–500 символов).

### 3) Эффект награды

При успешном начислении:
- увеличить `StudentSubjectProfile.xp` на `xp_amount` по выбранному предмету,
- пересчитать `level = (xp // 100) + 1`,
- создать запись `TutorReward`.

### 4) UI (кабинет репетитора)

На правой панели карточки выбранного ученика в `tutor_dashboard.html`:
- форма “Наградить XP”:
  - select предмета (из `selected_student.subject_profiles`)
  - input количества XP
  - input/textarea причины
  - кнопка “Начислить”
- блок “Последние награды” (например последние 10 записей) с отображением:
  - дата/время, предмет, +XP, причина

### 5) API / endpoints

Добавить POST endpoint:
- `tutor/award-xp/` (или `tutor/student/<id>/award-xp/`)
  - вход: `student_id`, `subject_id`, `xp_amount`, `reason`
  - выход: redirect назад на `tutor_dashboard?student_id=...`

---

## Тестирование

Unit/Integration (Django TestCase):
- репетитор начисляет XP по предмету: XP увеличился, level пересчитан, `TutorReward` создан
- запрет начисления не своему ученику (403 или redirect без эффекта)
- нельзя начислить по предмету, которого нет у ученика (без эффекта)
