# Приветствие на панели ученика по московскому времени

## Контекст

Сейчас приветствие на панели ученика зафиксировано как «Доброе утро» в шаблоне Django [student_dashboard.html](file:///workspace/core/templates/core/student_dashboard.html#L61-L85). Приложение работает по московскому времени (`TIME_ZONE = "Europe/Moscow"`, `USE_TZ = True`) в [settings.py](file:///workspace/examprep/settings.py#L152-L173).

## Цель

Сделать приветствие на панели ученика динамическим и зависящим от текущего московского времени:

- Доброй ночи
- Доброе утро
- Добрый день
- Добрый вечер

## Не цель

- Персонализировать приветствие по часовому поясу пользователя/браузера.
- Менять тексты/тональность приветствия (кроме перечисленных фраз).
- Делать анимации или дополнительные UI-элементы.

## Требования

### Функциональные

- Источник текущего времени — серверное время Django (`timezone.now()`), интерпретированное в `Europe/Moscow`.
- Границы интервалов (по Москве):
  - Ночь: 00:00–04:59 → «Доброй ночи»
  - Утро: 05:00–11:59 → «Доброе утро»
  - День: 12:00–17:59 → «Добрый день»
  - Вечер: 18:00–23:59 → «Добрый вечер»
- Приветствие отображается в текущем виде строки: `{greeting}, {first_name_or_username}! 👋`.

### Нефункциональные

- Логика должна быть переиспользуемой (чтобы можно было подключить в других шаблонах без копирования кода).
- Поведение не должно зависеть от часового пояса клиента.

## Предлагаемое решение

### Архитектура

- Вынести выбор приветствия в чистую Python-функцию (например, `core/greetings.py`), которая получает `now` (опционально) и возвращает строку приветствия.
- Обернуть функцию Django template tag’ом (например, `time_greeting` в `core/templatetags/time_greeting.py`), чтобы использовать её прямо в шаблонах.
- Заменить захардкоженный текст в `core/templates/core/student_dashboard.html` на вызов template tag’а.

### Почему template tag

- Приветствие относится к UI, но вычисление должно опираться на “московское время приложения”, а не на время браузера.
- Template tag даёт минимальное изменение шаблона и хороший re-use без протаскивания значения через каждый view.

## Точки изменения в коде

- Новый модуль логики: `core/greetings.py`
- Новый template tag: `core/templatetags/time_greeting.py`
- Шаблон панели ученика: `core/templates/core/student_dashboard.html`

## Тестирование

- Юнит-тест на функцию выбора приветствия, с параметром `now`:
  - Проверить значения на границах интервалов: 04:59/05:00/11:59/12:00/17:59/18:00/23:59/00:00 (московское время).
- (Опционально) Smoke-тест шаблона: убедиться, что страница рендерится и содержит один из допустимых вариантов приветствия.

## Риски и нюансы

- При `USE_TZ = True` время в базе/сервере может быть в UTC, поэтому нужно всегда использовать `timezone.localtime(..., ZoneInfo("Europe/Moscow"))` при определении часа.
