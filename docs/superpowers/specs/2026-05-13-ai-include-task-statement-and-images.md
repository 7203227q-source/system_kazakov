# ИИ-проверка фото: добавление условия и рисунков из задачи

## Цель
Улучшить точность ИИ-проверки развёрнутых задач по фото решения, добавив в запрос к модели:
- текст условия задачи (без HTML);
- рисунки/схемы из условия (как дополнительные изображения).

## Текущее поведение
В `api_verify_with_ai` в OpenRouter отправляется:
- текстовый промпт с правилами выставления баллов;
- одно изображение: фото решения ученика.

Текст и рисунки из условия задачи не передаются, из-за чего задачи с рисунками/графиками проверяются хуже.

## Требования
1) Для обычного режима проверки (кнопка “Проверить решение через ИИ”) в запрос добавляется:
   - `Условие:` — plain text, извлечённый из HTML условия (без `<script>/<style>`).
   - Доп. изображения из условия: все `<img>` из HTML условия (см. ниже правила).
2) Для режима сравнения `?mode=compare` поведение такое же: каждая из 5 моделей получает:
   - фото решения ученика;
   - текст условия;
   - изображения из условия.
3) Безопасность:
   - не передавать `data:`/`javascript:`/`file:` URL;
   - разрешать только:
     - относительные `/media/...` и `/proxy-image/...` (локальные или проксируемые),
     - либо `http/https` на разрешённых доменах `*.sdamgia.ru` (совместимо с существующим `proxy_image` allowlist).
4) Ограничения:
   - текст условия не ограничиваем по длине (как договорились);
   - картинки — без ограничения по количеству (как договорились).

## Извлечение данных из HTML
Источник HTML условия: `Task.get_content_for_theme()` (возвращает HTML из `TaskVariant.content`).

### Текст (plain text)
- Парсим HTML через `BeautifulSoup`.
- Удаляем теги `script`, `style`, `noscript`.
- Берём `get_text(" ", strip=True)` и нормализуем пробелы.

### Картинки
- Парсим `<img>` и берём `src` (fallback: `data-src`, `data-original`).
- Применяем фильтр URL (см. Требования/Безопасность).
- Дедупликация: сохраняем уникальные URL по порядку появления.

## Формат запроса к OpenRouter
Текущий формат user-message с `content: [ {text}, {image_url} ]` сохраняется.
Меняем порядок:
1) текстовый блок: промпт + `Условие: ...`
2) изображения:
   - фото решения ученика
   - затем все изображения из условия

## Тесты
1) Тест: в режиме `?mode=compare` количество вызовов OpenRouter остаётся 5, но payload включает в user-message:
   - текст “Условие:”
   - дополнительные `image_url` (мокаем HTML с двумя `<img>`).
2) Тест: фильтр URL отбрасывает `data:`/`javascript:` и сохраняет `/media/...` и `/proxy-image/...`.
