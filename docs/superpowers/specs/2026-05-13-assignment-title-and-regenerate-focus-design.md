# Генерация названий вариантов + фокус при замене задачи (tutor)

## Контекст
Репетитор создаёт вариант на странице генератора (`tutor_create_assignment`) и смотрит предпросмотр (`tutor_preview_assignment`), где может заменить одну задачу на случайную того же типа (`tutor_regenerate_task`).

## Требования
1) При генерации варианта автозаголовок должен строиться в порядке:
   **формат экзамена → имя ученика → название**.
2) Добавить возможность автогенерировать “название” по типу:
   - Домашняя работа
   - Тест
   - Контрольный тест
3) При автогенерации добавлять **порядковый номер по ученику** (№1, №2, ...), независимо от формата и типа.
4) Если репетитор ввёл `title` вручную — **не менять** его (“только автоген”).
5) При замене задания в предпросмотре фокус/скролл должен оставаться на новом задании (не нужно прокручивать страницу заново).

## Данные
Добавляем на `Assignment`:
- `kind` (строка): `homework | test | control_test` (nullable для обратной совместимости)
- `student_seq` (int): порядковый номер варианта по ученику (nullable для обратной совместимости)

Нумерация:
- `student_seq = (max(student_seq) по student) + 1`
- если у старых записей `student_seq` пустой, они не участвуют в max.

## UI (tutor_create_assignment)
- Порядок полей: **Формат экзамена** → **Кому назначить** → **Название варианта**
- Поле “Тип” (select) рядом с названием или под названием.
- При submit:
  - если `title` пустой → сервер генерирует `title` как:
    `"{exam_format.name} {exam_format.year} — {student_name} — {kind_label} №{student_seq}"`

## UX (tutor_preview_assignment)
- Каждой карточке задачи добавить `id="task-{{ task.id }}"`.
- `tutor_regenerate_task` после замены делает redirect на:
  - `/tutor/assignment/<assignment_id>/preview/?focus_task_id=<new_task_id>`
- На странице предпросмотра JS:
  - читает `focus_task_id`
  - делает `scrollIntoView({block:'center'})` по `#task-<id>`
  - подсвечивает карточку кратко (например, `ring-2 ring-indigo-400` на 1.5с)
  - убирает query параметр через `history.replaceState`

## Тестирование
1) Тест: при пустом `title` создаётся `Assignment` с `kind`, `student_seq`, и `title` в нужном формате.
2) Тест: `student_seq` инкрементируется по ученику.
3) Тест: `tutor_regenerate_task` редиректит на preview с `focus_task_id=<new_task_id>`.
