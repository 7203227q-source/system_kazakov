## Контекст

Нужно, чтобы задания из **вариантов** (Assignment) автоматически попадали в интервальное повторение на регулярной основе, а в тренажёре (student_practice) была кнопка «Добавить в интервальное повторение» (ручной режим).

Уточнения от заказчика:
- Автоматически добавляем в интервальное повторение **только из вариантов**.
- Автоматически добавляем **только неверные** (0 баллов / неверно).
- В тренажёре добавить кнопку «Добавить в интервальное повторение» (ручное добавление).
- В интерфейсе ученика добавить отдельный блок **«Повторить сегодня»** на дашборде.

## Текущее состояние в коде (важно)

- Есть модель `SpacedRepetition` и SM-2 алгоритм в `core/services.py` (`process_task_submission`, `get_due_tasks_for_student`).
- Текущий тренажёр `student_practice` выбирает задания через `get_adaptive_task_for_student` (на базе TaskLog), а не через `SpacedRepetition`. Поэтому `SpacedRepetition` сейчас практически не участвует в подборе задач.

## Решение (MVP)

### 1) Автодобавление в SRS из вариантов

Точки входа:
- `student_check_assignment_task` (кнопка «Проверить» в варианте)
- `api_verify_with_ai` (кнопка «Проверить ИИ»)
- `auto_expire_assignment_if_needed` (автозакрытие по дедлайну, выставляем 0 нерешённым)

Правило:
- если итоговый результат по задаче в варианте == 0 (или `is_correct=False` для задач 1-й части),
  - вызываем `process_task_submission(student, task, grade=1)` (ошибка) → создаёт/обновляет `SpacedRepetition` и ставит `next_review_date`.
- если результат > 0 — ничего не делаем (в SRS автоматически не добавляем).

### 2) Ручное добавление из тренажёра

В `student_practice`:
- добавить кнопку «Добавить в интервальное повторение»,
- при нажатии POST на новый endpoint `student_srs_add(task_id)`:
  - `SpacedRepetition.objects.get_or_create(student, task, defaults=...)`,
  - если запись уже есть — обновляем `next_review_date = today` (чтобы попало в «Повторить сегодня»),
  - не меняем XP/статистику (это просто “пометка на повторение”).

### 3) Блок «Повторить сегодня» на дашборде ученика

В `student_dashboard`:
- посчитать `due_srs_count = SpacedRepetition.objects.filter(student=user, next_review_date__lte=today).count()`
- вывести блок с количеством и кнопкой «Начать повторение» → ведёт в тренажёр в режиме SRS.

### 4) Режим SRS в тренажёре

Добавить параметр `?mode=srs`:
- если `mode=srs`, то `student_practice` подбирает задачу из `get_due_tasks_for_student(student)`:
  - берём первую по `next_review_date`,
  - если пусто — показываем «нет задач на повторение» и ссылку обратно на дашборд/обычный тренажёр.
- если `mode` не задан — сохраняем текущее поведение (`get_adaptive_task_for_student`).

### 5) (Опционально, но желательно) Завершение SRS-повтора

В MVP можно не внедрять градации 0–5 и оценку “вспомнил/не вспомнил”, но это естественное расширение:
- после ответа в режиме `mode=srs` вызывать `process_task_submission(student, task, grade=...)`:
  - если верно → grade=4/5,
  - если неверно → grade=1,
  - таким образом интервалы начнут «расти», а не повторяться ежедневно.

## Критерии готовности

- Неверные задачи из вариантов автоматически попадают в интервальное повторение.
- У ученика на дашборде есть блок «Повторить сегодня» с количеством задач и кнопкой запуска.
- В тренажёре есть кнопка «Добавить в интервальное повторение» (ручной режим).
- В тренажёре есть режим SRS (`?mode=srs`), который выдаёт задачи из очереди повторения.
