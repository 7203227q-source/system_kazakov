# Спецификация: Авторизация через соцсети (Google, VK) с выбором роли

## 1. Цель
Реализовать вход и регистрацию через Google и ВКонтакте с помощью библиотеки `django-allauth`. Так как платформа поддерживает разные типы пользователей (ученики, репетиторы, родители), новые пользователи из соцсетей должны проходить промежуточный этап выбора роли перед доступом к функционалу.

## 2. Архитектура и компоненты

### 2.1. Библиотеки
- `django-allauth` — стандартное и наиболее безопасное решение для интеграции OAuth2 (Google, VK) в Django.

### 2.2. Изменения в Базе Данных (Модель User)
- В поле `role` модели `User` добавляется новое значение по умолчанию: `unassigned` (Не выбрана).
- Существующая ручная регистрация по почте (где мы явно задаем `role='student'`) продолжит работать как раньше. Новые пользователи из соцсетей будут создаваться со статусом `unassigned`.

### 2.3. Маршрутизация и Флоу (User Flow)
1. Пользователь нажимает на кнопку "Войти через Google/VK" на странице логина или регистрации.
2. Происходит редирект на сторону соцсети, пользователь дает согласие.
3. Соцсеть возвращает пользователя на наш сайт. `django-allauth` автоматически создает аккаунт (сохраняя email, имя, фамилию).
4. Срабатывает кастомный адаптер авторизации (или middleware): если `user.role == 'unassigned'`, система перенаправляет его на новую страницу `/select-role/`.
5. На странице `/select-role/` пользователь видит три большие карточки: "Я Ученик", "Я Репетитор", "Я Родитель".
6. При клике на карточку отправляется POST-запрос, роль пользователя обновляется, и происходит финальный редирект на соответствующий дашборд.

### 2.4. Защита (Middleware / Декораторы)
- Если пользователь со статусом `unassigned` попытается вручную открыть URL любого дашборда (например, `/student/`), система должна перехватить запрос и вернуть его на страницу `/select-role/`.

## 3. Настройка на боевом сервере (Инструкция для админа)
Интеграция с соцсетями требует ключей API (Client ID и Secret Key).
- В Django Admin появится раздел "Social Applications".
- Пользователю (владельцу платформы) нужно будет создать приложение в [Google Cloud Console] и [VK Developers], получить ключи и вписать их в админке Django. До этого момента кнопки соцсетей будут выдавать ошибку настройки.

## 4. План реализации
1. Установка `django-allauth` и обновление `settings.py`, `urls.py`.
2. Изменение модели `User` (добавление роли `unassigned`) и создание миграции.
3. Создание view `role_selection_view` и красивого шаблона `select_role.html`.
4. Написание кастомного адаптера Allauth для правильного редиректа после логина.
5. Интеграция правильных ссылок (`{% provider_login_url 'google' %}`) в кнопки на страницах логина и регистрации.
