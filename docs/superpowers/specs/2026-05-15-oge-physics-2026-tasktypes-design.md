Дата: 2026-05-15  
Статус: draft (согласовано)

## Цель
Настроить в базе формат экзамена **ОГЭ по физике 2026**:
- корректные **баллы за каждую линию заданий** (TaskType.max_points);
- понятные **названия типов задач** (TaskType.name);
- корректный признак **тестовая часть / развёрнутая часть**.

Источник требований: официальные материалы ФИПИ по ОГЭ 2026 (физика).

## Проблема текущей логики
Сейчас в коде «часть 2» определяется эвристикой `task.exam_points > 1`.
Для ОГЭ по физике это неверно, т.к. в тестовой части есть задания с кратким ответом на **2 балла** (№1,2,4,12–14,16).

## Решение

### 1) Новый флаг в модели TaskType
Добавить поле:
- `TaskType.is_extended_answer: bool` — **True только для заданий с развёрнутым ответом**.

Заполняем:
- для ОГЭ физика 2026: `True` для №17–22, иначе `False`;
- для уже существующей ОГЭ математики: `True`, если `TaskType.name` содержит подстроку «развёрнутый ответ» (как в текущей миграции 0023).

### 2) Обновление логики в представлениях
В местах, где код делит задания на часть 1/2, использовать:
- `task.task_type.is_extended_answer`, а не `task.exam_points > 1`.

Это затрагивает:
- необходимость фото/черновика (QR для загрузки);
- подсчёт первичных баллов в итогах варианта.

### 3) Сидинг TaskType для ОГЭ Физика 2026
Создать (если нет) `Subject(name="Физика")`.
Создать (если нет) `ExamFormat(subject=Физика, name содержит "ОГЭ", year=2026, is_active=True)`.
