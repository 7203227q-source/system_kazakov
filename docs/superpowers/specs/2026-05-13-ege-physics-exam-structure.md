# ЕГЭ физика: структура КИМ в системе

## Цель
Завести в системе корректную структуру ЕГЭ по физике:
- номера заданий 1–26;
- максимальные первичные баллы по каждому номеру;
- разделение на часть 1 (тестовая) и часть 2 (развёрнутая),
и **чтобы логика решения** работала правильно:
- 1–20 решаются вводом ответа (без фото),
- 21–26 — загрузкой фото решения и ИИ‑проверкой.

## Проблема текущей логики
Сейчас “развёрнутые” задания определяются по эвристике `max_points > 1`.  
Для ЕГЭ физики это неверно, т.к. в **части 1 есть задания на 2 балла**, но они остаются тестовыми.

## Решение (модель)
Добавить в `TaskType` явный флаг:
- `is_extended_answer: bool` — “задание с развёрнутым ответом (нужно фото/ИИ)”.

Это позволит корректно разделять:
- тестовую часть (может быть 1 или 2 балла),
- развёрнутую часть (2–4 балла, фото).

## Данные: структура ЕГЭ физики
Экзамен состоит из 2 частей и 26 заданий:
- Часть 1: 1–20, максимум 28 первичных
- Часть 2: 21–26, максимум 17 первичных
- Итого максимум 45 первичных

### Баллы по номерам (часть 2 — точно по источнику)
Часть 2 (развёрнутая):
- 21 — 3
- 22 — 2
- 23 — 2
- 24 — 3
- 25 — 3
- 26 — 4

Часть 1 (тестовая) — в системе выставляем баллы по номеру согласно актуальному распределению (1 или 2); валидация решения “в одну цифру” не является целью этого изменения.

**Источник (структура 2025, совпадает с текущим КИМ):**
https://godege.ru/8bit/fizika-ege/demoversiya-ege-po-fizike-2025-goda/

## Миграция данных (backfill)
Проставить `is_extended_answer` для существующих форматов:
- ОГЭ математика: `number > 19` → `True`
- ЕГЭ математика: `number > 12` → `True`
- ЕГЭ физика: `number > 20` → `True`

## Изменения логики приложения

### 1) Страница решения варианта (student_solve_assignment)
Заменить определение “нужно фото / 2 часть” с `max_points_effective > 1` на:
- `task.task_type.is_extended_answer == True`

То есть:
- блок “Загрузите решение” показываем по `is_extended_answer` (и по requires_draft как раньше),
- при завершении “finish” проверяем наличие фото только для `is_extended_answer=True`.

### 2) ИИ‑проверка фото (api_verify_with_ai)
Разрешать проверку ИИ только если:
- `task.task_type.is_extended_answer == True`

### 3) Подсчёт результатов (student_assignment_summary)
Для тестовой части (`is_extended_answer=False`):
- баллы = `task.exam_points` если `is_correct=True`, иначе 0

Для развёрнутой (`is_extended_answer=True`):
- баллы = `submission.primary_score` (0..max)

## Тесты
1) Для ЕГЭ физики: тестовое задание на 2 балла **не** должно требовать фото.
2) Для ЕГЭ физики: задание 21+ требует фото и блокирует “Завершить вариант” без фото.
3) `api_verify_with_ai` возвращает `only_second_part` для тестового задания, даже если `max_points=2`, но `is_extended_answer=False`.
