# LaTeX в фидбеке ИИ + рендер формул у ученика

## Цель
Сделать так, чтобы ИИ при проверке задания мог писать формулы в LaTeX, а ученик видел эти формулы красиво отрендеренными в интерфейсе.

## Текущее состояние
- В `student_solve_assignment.html` уже подключён MathJax v3 (CDN).
- `feedback` сейчас вставляется в DOM как HTML (`innerHTML`), что:
  - небезопасно (потенциальный XSS, т.к. текст приходит от модели),
  - не гарантирует корректный рендер LaTeX (нужно вызывать typeset после динамической вставки).

## Требования
1) Промпт ИИ:
   - просим оформлять `feedback` в Markdown;
   - все формулы — только LaTeX:
     - инлайн: `$...$`
     - блочно: `$$...$$`
2) UI ученика:
   - перед отображением `feedback` делать HTML-экранирование (минимум `& < >`);
   - после вставки текста вызывать `MathJax.typesetPromise([container])`:
     - для обычной проверки “Проверить решение через ИИ”
     - для сравнения “Проверить 5 моделями” (в аккордеоне)
3) Совместимость:
   - MathJax уже подключён — переиспользуем его, не добавляя новых зависимостей.

## Изменения в коде
- `core/views.py`: дополнить prompt инструкцией про LaTeX.
- `core/templates/core/student_solve_assignment.html`:
  - добавить `escapeHtml()` в JS;
  - заменить прямую подстановку `${data.feedback}` на `${escapeHtml(data.feedback)}`;
  - добавить `typesetMath(el)` и вызывать после обновления блоков результата.
