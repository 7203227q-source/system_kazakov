## Контекст

Пользователь хочет:
1) Везде видеть баллы, которые получает за решения (в т.ч. в «последних решениях/ошибках»).
2) Исправить порядок задач в варианте (иногда первым отображается «задача №8» и «номера съезжают»).

Текущее состояние:
- Баллы X/Y частично уже отображаются в `student_history` и `student_practice_result`.
- В `tutor_dashboard` блок «последние ошибки» не показывает баллы.
- На `student_dashboard` нет блока «последние решения» (хотя `recent_submissions` в view есть).
- Вариант хранит задачи в M2M (`assignment.tasks`), порядок по умолчанию не гарантирован → отображение может быть случайным.

## Цели

1) Добавить отображение «Баллы: X/Y» в карточки последних попыток:
   - на дашборде ученика (последние решения),
   - на дашборде репетитора (последние ошибки выбранного ученика).
2) Гарантировать стабильный порядок задач в варианте:
   - по номеру типа (`task.task_type.number`), затем по `task.id`.

## Решение

### A. Блок «Последние решения» на student_dashboard

- В `student_dashboard` использовать уже подготовленный queryset `recent_submissions` (или расширить `select_related('task', 'task__task_type')`).
- В шаблоне `student_dashboard.html` добавить блок со списком последних N попыток.
- Для каждой попытки показывать:
  - ID/тип,
  - статус (верно/неверно),
  - «Баллы: X/Y», где:
    - `Y = sub.task.exam_points`,
    - `X = sub.primary_score` если `Y>1`, иначе `1/0` по `sub.is_correct`.

### B. «Баллы X/Y» в последних ошибках на tutor_dashboard

- В шаблоне `tutor_dashboard.html` в блоке `recent_mistakes` добавить бейдж «Баллы: X/Y» по той же формуле.

### C. Стабильная сортировка задач в варианте

Во всех местах, где отображаются задачи варианта, заменить `assignment.tasks.all()` на:

`assignment.tasks.select_related('task_type').order_by('task_type__number', 'id')`

Минимальный набор:
- `tutor_preview_assignment`
- `student_solve_assignment`
- `student_assignment_summary`

## Критерии готовности

- На дашборде ученика появился блок «Последние решения» с бейджем «Баллы X/Y».
- В панели репетитора в «Последние ошибки» видно «Баллы X/Y».
- Варианты всегда отображаются в предсказуемом порядке (сначала тип 1, затем 2, …), номера в списке больше не «съезжают».
