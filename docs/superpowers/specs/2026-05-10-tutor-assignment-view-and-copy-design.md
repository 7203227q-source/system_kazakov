## Контекст

Репетитору нужно открывать вариант ученика и видеть те же задания (условие) одновременно с учеником — особенно при онлайн-занятиях. Также нужна кнопка «Копировать», чтобы быстро перенести условие (текст + изображение) на онлайн-доску.

## Цели

1) Добавить репетитору read-only просмотр варианта (задачи + решения) по ссылке из панели репетитора.
2) Добавить кнопку «Копировать» у каждой задачи:
   - копировать текст условия (без HTML),
   - и первое изображение из условия (если есть).
3) Сохранить безопасность доступа: репетитор видит только варианты своих учеников.

## Решение

### A. Страница «Просмотр варианта» для репетитора

- Новый view: `tutor_assignment_view(request, assignment_id)`:
  - доступ: `role in ['tutor','admin']`
  - если `tutor`: проверка `assignment.tutor == request.user`
  - загрузка задач: `assignment.tasks.select_related('task_type').order_by('task_type__number','id')`
  - тема отображения: `request.user.preferred_theme` (как выбрано в требованиях)
- Новый шаблон: `core/tutor_assignment_view.html`:
  - заголовок: ученик + название варианта
  - список задач:
    - номер (тип), fipi_id/id,
    - условие (`task.get_content_for_theme(theme)`),
    - решение (`task.get_solution_for_theme(theme)`).

### B. Кнопка «Копировать» (текст + 1-е изображение)

- В шаблоне у каждой задачи есть кнопка `data-copy-task`.
- JS логика:
  - берём контейнер условия, получаем `innerText` для текста.
  - ищем первый `<img>` в контейнере; если найден:
    - нормализуем URL: если внешний — берём через `/proxy-image/?url=...` (same-origin fetch).
    - `fetch` → `blob`, затем `navigator.clipboard.write([new ClipboardItem({[blob.type]: blob, 'text/plain': textBlob})])`.
  - если нет поддержки `ClipboardItem` или не удалось загрузить изображение — fallback на `navigator.clipboard.writeText(text)`.

### C. Встраивание в UX

- Добавить ссылку «Просмотр»:
  - в карточки «Варианты ученика» на `tutor_dashboard`,
  - на странице `tutor_assignment_summary`.

## Критерии готовности

- Репетитор может открыть просмотр варианта и видеть условие+решение.
- Кнопка «Копировать» копирует текст и (если есть) изображение; без изображения копирует только текст.
- Не-репетитор не получает доступ к чужим вариантам.
