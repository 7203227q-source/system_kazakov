# ИИ-проверка для развернутой части (2 часть)

## Цель
Подключить реальную ИИ-проверку (OpenRouter vision) для задач развернутого ответа (2 часть) по фото решения.

## Текущее состояние
- Уже есть модель `Submission` с полями результата (`primary_score`, `is_correct`, `ai_feedback`, `image_url`).
- Уже есть UI у ученика для загрузки фото (QR/desktop) и кнопка “Проверить решение через ИИ”.
- Уже есть API `POST /api/submission/<id>/verify/` (`api_verify_with_ai`), но:
  - разрешает проверку любых задач;
  - если OpenRouter не настроен, возвращает “заглушку” (random) и записывает результат.

## Требования
1) ИИ-проверка доступна **только для 2 части**:
   - определяем 2 часть как `task.exam_points > 1`.
2) Заглушку отключаем:
   - если `OPENROUTER_API_KEY` не задан или не выбрана модель `SubjectAIConfig.photo_analysis_model` — возвращаем ошибку (400), ничего не пишем в `Submission`.
3) UI:
   - кнопка “Проверить через ИИ” показывается только для 2 части;
   - если API вернул ошибку, показываем человеку понятное сообщение (например, “ИИ не настроен: выберите модель в настройках предмета”).

## Источники конфигурации
- Модель для предмета: `SubjectAIConfig.photo_analysis_model` (по `task.topic.subject`).
- Ключ: `OPENROUTER_API_KEY` в окружении.

## Проверка/тесты
1) Тест: попытка `POST /api/submission/<id>/verify/` для задачи с `exam_points == 1` возвращает 400.
2) Тест: если ключ/модель отсутствуют, endpoint возвращает 400 и не меняет `Submission.primary_score/is_correct/ai_feedback`.
3) Smoke: для 2 части и настроенного ключа/модели endpoint возвращает JSON с `primary_score/is_correct/feedback`.
