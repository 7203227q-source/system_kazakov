# Сравнение ИИ-проверки 5 моделями (временный режим)

## Цель
Дать возможность ученику на задаче 2 части запустить ИИ-проверку решения по фото сразу 5 разными моделями и сравнить качество (баллы/фидбек).

## Требования
1) Обычная проверка остаётся как есть: `SubjectAIConfig.photo_analysis_model`.
2) Режим сравнения:
   - запускается отдельной кнопкой “Проверить 5 моделями” на странице решения ученика;
   - доступен только для задач 2 части (effective max_points > 1);
   - использует ровно 5 моделей, заданных в админке;
   - возвращает результаты на страницу и **не сохраняет их в базу**;
   - не изменяет `Submission.primary_score/is_correct/ai_feedback`.
3) Админка:
   - добавить 5 слотов моделей для сравнения на уровне предмета (`SubjectAIConfig`).
4) UI:
   - результаты показывать как список/аккордеон: модель → primary_score/max → feedback.

## Данные
Добавить в `SubjectAIConfig`:
- `photo_compare_model_1..photo_compare_model_5` (FK → `OpenRouterModel`, nullable)

## API
Расширить `POST /api/submission/<id>/verify/`:
- если query `?mode=compare`:
  - проверить права/наличие фото/2 часть как в обычном потоке;
  - выбрать 5 моделей из `SubjectAIConfig`;
  - сделать 5 запросов в OpenRouter (можно последовательно);
  - вернуть JSON:
    - `mode: "compare"`
    - `max_points`
    - `results: [{model, primary_score, is_correct, feedback}]`
  - не трогать поля `Submission`.

## Ограничения/защита
- Лёгкий rate-limit на сессию/сабмишн (например, не чаще 1 раза в 30 секунд).

## Тесты
1) Тест: compare-режим возвращает 400 если заданий не 2 части.
2) Тест: compare-режим возвращает 400 если не настроены все 5 моделей.
3) Тест: compare-режим не меняет `Submission` и возвращает 5 результатов (мокаем `requests.post`).
