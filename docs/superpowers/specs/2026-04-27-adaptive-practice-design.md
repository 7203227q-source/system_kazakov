# Спецификация: Адаптивный тренажер (Алгоритм интервального повторения по темам)

## 1. Концепция
Вместо выдачи случайных задач (random), раздел "Тренажер" (`student_practice`) будет использовать интеллектуальный алгоритм выбора задачи.
Алгоритм базируется на анализе прошлых попыток (`TaskLog`) и реализует **интервальное повторение на уровне Тем (Topics)**, а не конкретных задач. Это идеально подходит для математики и физики.

## 2. Логика алгоритма выбора задачи
Когда ученик заходит в "Тренажер", система выполняет следующие шаги:

1. **Сбор статистики по темам:**
   Для каждой темы (Topic) из предметов, которые изучает ученик, вычисляется:
   - `avg_score` (средний процент правильных решений)
   - `last_practiced` (дата последнего решения задачи из этой темы)

2. **Расчет приоритета (Priority Weight):**
   Каждая тема получает "вес" (вероятность выпадения). 
   - *Фактор забывания (Forgetting Factor)*: Чем больше дней прошло с `last_practiced`, тем выше вес. `weight += days_since * 0.1` (до определенного предела).
   - *Фактор ошибок (Error Factor)*: Чем ниже `avg_score`, тем выше вес. Если ученик решает тему на 20%, она будет выпадать чаще, чем та, которую он решает на 90%.
   - *Новые темы*: Темы, которые ученик еще **никогда** не решал, получают высокий базовый приоритет (чтобы обеспечить покрытие всего материала).

3. **Выбор Темы:**
   Темы сортируются по итоговому весу (Priority) по убыванию. Берется Топ-3 самых приоритетных тем, и из них выбирается одна случайная (чтобы добавить элемент непредсказуемости и избежать зацикливания на одной теме).

4. **Выбор Задачи:**
   Внутри выбранной темы система ищет `Task`, которую ученик:
   - Еще никогда не решал правильно.
   - Либо решал очень давно.
   Если таких нет (прорешал всё в теме), берется случайная задача из этой темы.

## 3. Изменения в коде
- **`core/analytics.py`**: Добавить новую функцию `get_adaptive_task_for_student(student)`, которая реализует вышеописанную логику на основе Django ORM (`TaskLog.objects.filter(...)`).
- **`core/views.py`**: В функции `student_practice` заменить `task = Task.objects.order_by('?').first()` на вызов `get_adaptive_task_for_student(request.user)`.

## 4. Ограничения MVP
- Алгоритм работает в реальном времени при открытии страницы тренажера.
- Учитываются только те предметы, которые ученик добавил себе в профиль (через `StudentSubjectProfile`). Если предметов нет, выдается случайная задача из любых доступных.
