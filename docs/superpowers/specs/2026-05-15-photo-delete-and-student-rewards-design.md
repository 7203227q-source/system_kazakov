# Спека: удаление фото решения + награды XP видны ученику

Дата: 2026-05-15  
Статус: draft (готово к ревью)

## 1) Удаление фото решения учеником

### Проблема
Ученик может случайно прикрепить фото не к той задаче. Сейчас нет простого способа удалить/сбросить фото и прикрепить заново.

### Цель
Дать ученику возможность удалить прикреплённые фото решения (стр.1/стр.2) у конкретной попытки (Submission).

### Правила доступа
- Удалять фото может **только ученик-владелец** `Submission.student`.

### Поведение
На странице решения варианта (где показывается превью загруженного фото) добавить кнопку **«Удалить фото»**.
По нажатию:
- очищаем `image_url` и `image_url_2`;
- сбрасываем ИИ-вердикт и связанные поля (чтобы не оставался вердикт от старого фото):
  - `ai_feedback`
  - `ai_recognized_solution`
  - `ai_mistakes_json`
  - `ai_verdict_json`
  - `primary_score`
  - `is_correct`
- UI возвращается к состоянию «Загрузите решение».

### API
Добавить endpoint:
- `POST /api/submission/<id>/clear-images/`
  - auth required
  - 403 если submission не принадлежит текущему ученику
  - response: `{status: "ok"}`

### Деградация / ошибки
- Если фото уже нет — endpoint возвращает `ok` (идемпотентность).

## 2) Сообщение репетитора при награждении XP видно ученику

### Проблема
Репетитор при награждении XP вводит `reason` (сообщение), но ученику непонятно, куда оно попадает — сейчас список наград виден только на дашборде репетитора.

### Цель
Показывать ученику список последних наград XP с текстом `reason`.

### Поведение в UI
На **дашборде ученика** добавить блок **«Награды от репетитора»**:
- показываем последние N (например 10) наград `TutorReward` для текущего ученика;
- у каждой: `+xp_amount XP`, предмет, дата/время, и текст `reason` (если есть).

### Источник данных
Используем существующую модель `TutorReward` (ничего не меняем в схеме БД).

### Доступ
- Ученик видит только награды, где `TutorReward.student = текущий ученик`.

## Тестирование (минимум)
1) Endpoint `clear-images`:
   - студент может очистить свои фото, поля становятся `None`
   - чужой студент получает 403
2) Student dashboard:
   - награды рендерятся, reason отображается
   - награды другого ученика не отображаются

## Критерии приёмки
- Ученик может удалить прикреплённое фото решения и загрузить новое.
- После удаления фото на странице не отображается старый ИИ-вердикт/оценка.
- На дашборде ученика виден список наград XP от репетитора с сообщением (reason).
