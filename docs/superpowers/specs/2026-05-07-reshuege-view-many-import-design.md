## Цель

Добавить поддержку ссылок на подборки задач РешуЕГЭ вида `/test?a=view_many...` в админ‑импорте `/platform-admin/reshuege-import/`, чтобы можно было вставлять одну ссылку на список вместо ручного списка ID.

## Поведение

- Поле ввода принимает строки:
  - ID задачи (например `116125`)
  - ссылка на задачу (`/problem?id=...`)
  - ссылка на список (`/test?a=view_many...`)
- Если введена ссылка `view_many`, система:
  - загружает HTML страницы списка
  - извлекает ID задач (в порядке отображения)
  - при включенном “пропускать уже загруженные” отбрасывает существующие задачи и добирает следующие
  - останавливается после сохранения до 25 задач за запуск
- Фильтры “без ответа” и “прототип” применяются как и ранее.

## Отчетность

- В статистику добавляются:
  - `expanded`: сколько ID найдено на странице списка
  - `recognized`: сколько кандидатов получилось после разбора ввода и (если включено) фильтра существующих
- В таблице отчёта добавляется строка `view_many` с количеством извлечённых ID.

## Ограничения

- Если страница списка недоступна (капча/403/таймаут), импорт фиксирует ошибку и продолжает обработку остальных строк.
- За один запуск сохраняется не более 25 задач.
