Система подготовки к экзаменам (Система Казакова) — краткое резюме функционала

Роли:
- Ученик, Репетитор, Родитель, Администратор (+ промежуточная роль unassigned).

Ученик:
- Дашборд по предметам, прогресс (XP/уровень), история решений.
- Тренажёр: случайные задания, сохранение попыток и начисление XP.
- Решение вариантов (назначенных репетитором), итоговая сводка по варианту (баллы и выполненность).

Репетитор:
- Дашборд учеников: активные/решённые варианты, баллы (первичный X/Y и вторичный /100), аналитика.
- Графики мастерства/прогноза по предмету и периодам, решаемость по номерам задач с цветовой индикацией.
- Просмотр варианта ученика (условие + решение) и кнопка «Копировать» (текст + первое изображение) для онлайн-доски.
- Журнал решений ученика, контакты/заметки, статус оплаты.

Родитель:
- Дашборд прогресса ребёнка, предметы/цели, мастерство/прогноз, статус оплаты.
- Привязка ребёнка по коду ученика (parent_invite_code).

Чат (внутренняя система сообщений):
- Диалоги ученик↔репетитор, родитель↔репетитор, поддержка вложений и непрочитанных.

Администратор:
- Кастомная админ-панель (без Django admin) со списками и действиями (в т.ч. удаление пользователей).
- Инструменты импорта/управления задачами и системные страницы.

Задания и варианты:
- Банк задач с типами/номерами, подтипами, баллами ЕГЭ, разными темами (classic/dota/cs2/ussr).
- Варианты репетитора: сборка, публикация ученику, стабильная сортировка задач по номеру.

Технические детали:
- Поддержка QR-загрузки черновика/фото решения и API проверки.
- Прокси для изображений (используется, в т.ч., для копирования изображения в буфер обмена).
